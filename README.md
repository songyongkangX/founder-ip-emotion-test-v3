# 创始人 IP 情绪风格测评

前台测评继续使用 GitHub Pages 静态部署；后台登录、学员数据和管理员邀请由 Supabase 提供。

## 功能

- 33 道测评题（含 2 道可选八字题），自动累计怒、喜、哀、惧、爱、恶、欲七类情绪分数
- 8 道加权 MBTI 辅助题，每个维度通过不同情境交叉判断；接近持平时用内容表达情境复核，始终输出标准四字母类型
- 自动生成主情绪、辅助情绪、内容比例、视觉/听觉建议、八类外在风格对照与可拍选题
- 答题进度与结果自动缓存在当前浏览器，重新进入可继续答题、查看上次结果或重新开始
- 学员开始前填写姓名/昵称、联系方式与班级/渠道，完成后将答题内容和结果安全保存到管理后台
- `/admin/` 管理后台支持首次开通、邀请管理员、搜索筛选、完整答题查看、CSV 导出和删除记录
- 使用 html2canvas 将完整结果页导出为 PNG 图片，并保留 SVG 兜底方案
- 支持移动端布局

如果需要本地预览，可在项目目录运行任意静态服务器，例如：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`。

## 分享链接

外部结果链接支持通过 URL 参数直接打开结果页：

```text
https://你的域名.com/?answers=x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x.x
```

答案会编码在 URL 中。打开分享结果不会产生新的后台提交；学员从首页完成正式测评时，才会在本人同意后保存到后台。将本文件夹部署到 GitHub Pages、Netlify、Vercel 静态托管或自己的域名后，访问带有 ?answers=... 的链接即可直接打开结果页。

## 后台部署

首次部署需要创建 Supabase 项目、执行数据表脚本并部署两个安全函数。完整步骤见 [BACKEND_SETUP.md](BACKEND_SETUP.md)。首次开通凭证必须保存在 Supabase 环境变量中，不能写入公开仓库。
